Unit tests: `pytest`. Parser tests use saved Google Jobs pages in `tests/fixtures/` (trimmed to job cards). These are not in the public repo because they contain third-party job listings. To recreate them, save the HTML of a `https://www.google.com/search?q=...&udm=8` page as `us_software_ny.html` and a German one as `de_softwareentwickler_berlin.html`. Without them, those tests are skipped.
